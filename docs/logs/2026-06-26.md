# 2026-06-26 — AI geo-bug (Gemini/Hong Kong) fix · single-Supabase-login Q&A

**Prod cuối ngày:** Pages `a63c0c53` · Worker `9e730935` (placement region) · D1 0038.

## ✅ FIX: AI (dịch / tóm tắt / bot) không chạy ở VN — gốc là **Hong Kong egress**, không phải mạng VN
Triệu chứng (Luân test): translate/summary/chatbot **502 / "could not reach" / Summary frozen** khi user ở VN (hoặc IP VN), **Hàn thì OK**; **STT Deepgram VẪN chạy**.

**Cách chẩn đoán:** thêm log `cfDiag` (colo+country) + timeout vào các call Gemini (`worker/src/ai.ts`), deploy, `wrangler tail` lúc Luân trigger từ VN → bắt được:
```
POST /translate-batch  (error) [colo=HKG country=HK]
Gemini 400 FAILED_PRECONDITION: "User location is not supported for the API use."
```
**Root cause:** mọi call AI là **server-side** (browser→Worker→Gemini) nên ISP/mạng VN của user KHÔNG nằm trong đường đi (vì vậy Google vẫn vào được bình thường). Cloudflare chạy Worker ở **PoP gần user nhất = Hong Kong (HKG)** cho user VN/SEA, và **Gemini API CHẶN Hong Kong** (VN thì Gemini hỗ trợ, nhưng egress ra từ HK thì 400). Deepgram không có rule vùng → luôn chạy → đó là cách tách lỗi về riêng Gemini. (Lỗi nổi tiếng: dev Úc/US cũng dính khi Worker rớt vào PoP HKG.)

**FIX (thuần Cloudflare, KHÔNG relay):** **Worker Placement region hint** trong `worker/wrangler.jsonc`:
```jsonc
"placement": { "region": "aws:ap-southeast-1" }   // Singapore — Gemini-supported
```
→ Worker chạy ở data-center gần Singapore → call Gemini **egress từ SG** (vùng hỗ trợ) → hết 400. Luân xác nhận **work**. (Alternatives: `aws:ap-northeast-2` Seoul / `aws:ap-northeast-1` Tokyo — đều hỗ trợ; **TUYỆT ĐỐI không `aws:ap-east-1` = HK**.)
- Giữ lại trong worker: **timeout 20s** cho call Gemini (`geminiFetch` + `AbortSignal.timeout`) = chống "frozen" + `cfDiag` log (chẩn đoán sau này).
- Đã thử **Smart Placement** (`mode:smart`) nhưng bỏ — nó tối ưu theo D1 (APAC), không chắc thoát HK; region hint **explicit** mới chắc.
- Đã chuẩn bị + rồi **xóa** phương án **relay** (Railway) theo yêu cầu Luân ("chỉ dùng Cloudflare").
