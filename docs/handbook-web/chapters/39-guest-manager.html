Guest manager

The all-projects view for managing the clients you've issued — a shortcut into the credential tools covered in the Clients part.

Every project's guests, together

The sidebar's Guest manager gathers the clients you've issued across all your projects into one list, so you can find, edit, reset or revoke a guest without opening each project. It's the same toolset described in Client credentials — just the central door to it.

Each guest stays scoped to its own project; the manager only saves you hunting for the right folder.
