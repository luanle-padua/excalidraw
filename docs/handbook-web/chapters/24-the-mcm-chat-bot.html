The MCM chat bot

Drop the MCM Bot anywhere on the canvas, or call @bot in chat, and ask it to summarise, list decisions, or answer a question about the meeting.

Drop the bot and ask a question

  1. In the toolbar, click the bot icon (tooltip Ask MCM Bot). The pointer enters placing mode and a small bot ghost follows your cursor.
  2. Click anywhere on the canvas to drop it. Click outside the canvas, or press Esc, to cancel placing.
  3. A small prompt box opens at the drop point, with the placeholder Type your request… (e.g. summarize the meeting, list decisions).
  4. Type any request — summarise, list decisions, translate this, and so on — then click Send or press Enter. Use Shift+Enter for a new line, Esc or × to cancel.
  5. A framed panel reading 🤖 Working… appears at the drop point, then is replaced in place by the bot's answer.

→ The answer lands as a dark, cyan-bordered 🤖 MCM BOT panel — a normal, movable canvas element everyone in the room can see and reposition.

Note

Nothing fires automatically. The bot only runs on your explicit click, so there's no risk of two people triggering it at once — the prompt box is local to you; only the answer panel is shared.

Host-only

Any participant can drop the bot — there is no host gate in the tool itself. Access is checked server-side by room membership, so only people actually in the meeting can run it.

Anatomy of an answer
  1. 1 Bot header — every answer panel opens with 🤖 MCM BOT in monospace so it's unmistakably the bot's, not a peer's note.
  2. 2 Answer body — light text on a dark panel, wrapped to the frame width. This is what the bot wrote in reply to your request.
  3. 3 Cyan frame — the panel is a real rectangle with bound text. Drag it, resize it, or delete it like any element; changes sync to the room.
  4. 4 Authored by MCM Bot — the panel is stamped with the bot's identity, so it's excluded from the meeting context the bot reads next time (it never quotes its own answers back to you).

@bot — the in-chat assistant

Type @bot followed by a question to ask the room's AI assistant, MCM Bot. Pick it from the @ picker — labelled MCM Bot with the note Ask AI about the design / project — or just type @bot by hand.

When you send a line containing @bot, your message posts as normal and the assistant starts working. A bot bubble with an animated three-dot thinking indicator appears while it composes. The bot reads context from the room — the last several chat lines, the full voice transcript so far, text written on the canvas, who is present, and the library file names — then replies in your preferred language. Its answer lands as a distinct robot-avatar bubble from MCM Bot.

Ask in plain language: @bot summarise the open questions or @bot what did we decide about the logo?
How @bot answers Your @bot line → thinking dots → MCM Bot gathers room context → reply bubble in your language.
If it can't answer

If the assistant has nothing useful it replies Sorry, I couldn't answer. Try again later. If the connection or AI service fails it replies I can't reply right now (connection or API problem). Either way the thinking indicator clears.

When translate or the bot misbehaves

No Translate pill appears — Nothing selected, more than one element selected, or you selected a translation line rather than a source.

Click a single text element. Translating a translation is blocked on purpose, so the pill hides on those grey lines. → 9.2

Pill shows Refresh translation, not Translate — You edited the source text after translating, so the lines below it are now stale and faded.

Click Refresh translation to re-translate every out-of-date line in one pass. → 9.4

Clicking a language adds nothing — The source is empty/whitespace, or the provider is unavailable and returned the original text.

Make sure the note has real text. If the provider is down, Canvas M intentionally adds no line; try again later. → 9.5

Translation moved when I dragged the note — Expected. Translation lines are linked to their source and shift by the same offset to stay together.

Nothing to fix — move the source and the pair travels as one. Delete the source to remove its translations too. → 9.2

Bot panel says "The bot hit an error, try again." — The request to the bot failed or the server returned an error.

Press the bot icon again, drop a fresh prompt, and resend. The error text replaces the loading frame in place. → 9.6

Dropped the bot but no prompt box — You clicked outside the canvas area, which cancels placing.

Re-arm the bot from the toolbar and click inside the canvas to drop it. → 9.6

Note

The bot reads the meeting's chat, voice transcript, canvas notes (with authors), participants and shelf files as context — but it skips its own previous answers, so it won't loop on "no info" replies.
