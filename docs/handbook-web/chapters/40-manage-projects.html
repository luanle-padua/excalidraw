Manage projects

The project browser on your dashboard — finding, grouping and opening the projects you belong to. Full administration lives in the Project management part.

Open the Manage projects page

  1. In the left sidebar, look below My meetings and Invited / Upcoming for the Manage projects item (folder-kanban icon).
  2. Click it. The middle column switches to the project management page, titled Manage projects.
  3. At the top sits a Search projects… box, a grid/list View toggle, and a New project button.
  4. Projects are grouped: My projects (folders you belong to) and Invited (folders another department invited you into for one meeting), each with a count.
  5. Click any project tile or row to drill into its detail. Click All projects to come back to the list.

→ You're on the dedicated admin surface. The grid (card) view is the default — covers carry the page; the list view is a denser alternative.

Note

The toolbar (search + view toggle + New project) hides entirely when you have no projects yet — the empty state carries its own create button instead.

What the list shows

Folders you belong to, sorted by most recently updated, under the My projects (n) heading. Tiles show cover, name, stage pill and a code · client · location meta line.

Folders another department invited you into for one meeting, under Invited (n), each badged Invited. These open read-only — no admin.

A folder-kanban illustration with “No projects yet” and the hint “Create your first project to start organizing meetings.”, plus a New project button.

When a search matches nothing you'll instead see “No projects match "{q}"” with a Clear search link. If the list itself fails to load, it reads “Couldn't load — check your network connection.” with a Retry button.
