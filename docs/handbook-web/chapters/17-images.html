Images

Drop an image onto the canvas like any element — the simplest thing you can bring into a meeting.

Add an image to the canvas

An image — a photo, a screenshot, an exported render — goes onto the canvas the same way as any file: drag it straight onto the board, or upload it to the room library and click to place it. Canvas M accepts standard picture formats (PNG, JPG and the like).

Once placed, an image is a normal canvas element: move, resize, lock it, or draw and stamp on top. To brand an image with a stamp so the mark stays attached, see Stickers & stamps.
