CAD drawings (DXF)

Open a DXF drawing two ways — read it in place on the canvas, or open it in the docked CAD viewer with layers, fit and lock.

Anchors, panes, and what your peers see

Every document you open started life as an upload in the room library — the bar on the right where files are grouped under PDF documents, CAD drawings, and IFC models. Dropping one onto the canvas creates an anchor: a tile that shows the document in place, sized and positioned like any other element.

There are two ways to look at a document, and they behave differently. A PDF shows its page directly on the canvas inside the anchor — you read it where it sits. A DXF drawing or an IFC model can be explored right on the anchor too, or opened in a dedicated pane that docks to the right edge of the screen for a full interactive viewer with its own toolbar. The canvas anchor is the shared object; the pane is your personal workspace for inspecting it.

What you leave on the canvas — the page, the layers left showing, the angle you parked a model at — is shared with the room. The orbiting, slicing and measuring you do while exploring stays on your screen.
Library file → canvas anchor → docked viewer pane An uploaded file becomes a canvas anchor; DXF and IFC anchors can additionally open in a right-docked pane.
Good to know

Canvas M accepts only four kinds of file. If someone tries to add anything else, the room reports “Only images, DXF, PDF and IFC are supported for now.” and skips it.

Read a DXF without opening a pane

  1. Right-click a DXF anchor and choose Edit DXF (pan / zoom). The drawing comes alive in place — drag to pan, scroll to zoom.
  2. Click 📋 Layers to open Layers (N). Every row carries the layer's own colour swatch; tick or untick to show or hide it, or use All and None to switch the lot.
  3. ↻ Fit reframes the whole drawing; × Exit (or Esc) leaves edit mode. Right-clicking also offers Reset fit (back to full view).

→ Unlike the CAD pane, a DXF edited here on the canvas is the shared object: the layers you hide and the view you leave are saved to the anchor and seen by everyone in the room.

Two viewers, on purpose

Edit a DXF on the canvas when the whole room should see the change. Open the same drawing in the CAD view pane (next) when you want a big, private workspace — pane changes stay with you.

Open a DXF in the CAD view

  1. Click the CAD view button in the canvas toolbar (the blueprint icon, tooltip “CAD view — open DXF in a pane”).
  2. A popover titled DXF in library lists every drawing in the room. Pick one to open it as a tab in the right-docked pane.
  3. Alternatively, right-click a DXF anchor on the canvas and choose Open in CAD view.
  4. Each file opens in its own tab marked 📐; click a tab to switch, click its × to close just that drawing.
  5. Drag the left edge of the pane (the resize handle) to make the viewer wider or narrower.
  6. Close the whole pane with the × in the top-right corner.

→ The DXF loads into an interactive viewer. Pan by dragging, zoom with the scroll wheel. Re-opening a drawing that is already a tab simply switches to it rather than duplicating.

Note

If the popover says “No DXF files in the library yet.” with the hint “Upload .dxf via the library bar on the right.”, there is simply nothing to open yet.

CAD view toolbar
  1. 1 Layers — opens the Layers (N) panel. Tick or untick each layer to show or hide it; the colour swatch matches the DXF layer colour. All turns everything on, None turns everything off.
  2. 2 Fit — resets the view to frame the whole drawing (tooltip “Fit DXF to pane (reset the view)”).
  3. 3 Lock / Locked — freezes pan and zoom so you cannot nudge the drawing by accident. Click again to unlock; the tooltip reads “View is locked — click to unlock pan/zoom” when active.
  4. 4 Tab strip — one tab per open drawing, each with a × to close it; the pane × at top-right closes the entire CAD view.

Note

The CAD view is a 2D drawing viewer — it has no measure, snap, or unit tools (those belong to the 3D model view). And mind where a change lives: layers toggled in the pane are yours alone, while layers toggled on the canvas anchor are shared with the room.

Document viewing — troubleshooting

A PDF / DXF / IFC tile shows “Waiting for … file from peer…” — The file bytes have not reached you yet — the person who added it is still syncing it across.

Wait a moment; it fills in automatically once the file arrives. No action needed. → 12.1

A model sits in the library a few seconds before it will open — An IFC is converted to a lightweight 3D model when you upload it; bigger buildings take a little longer.

Wait for the conversion to finish — it only happens once, at upload. → 12.2

“Maximum DXF files already open” (or “Maximum 3D models already open”) — Every live viewer slot is in use — heavy 3D models run at most two at once, DXF drawings up to four.

Close another open file or tab, then try opening this one again. → 12.7

“Couldn't read DXF: …” or “Couldn't read IFC model: …” — The file is corrupt or in an unsupported variant; the message after the colon is the underlying reason.

Ask the owner to re-export and re-upload the file. (A .dwg won't open at all — it must be exported to .dxf.) → 12.5

A DXF opens but all its text and dimensions are missing — The drawing relies on fonts the viewer doesn't have, so labels are dropped while the geometry still draws.

The lines are accurate; this is a display limit, not lost data. Re-export with standard fonts if the labels matter. → 12.5

A DXF tab shows “DXF file not found” — The tab is left over from a different meeting; its file is not in this room's library.

Close the phantom tab — Canvas M also prunes these automatically once the library loads. → 12.5

The 3D toolbar buttons are all greyed out — The model is still loading (“Loading 3D model…”) or has no storeys / objects to show.

Wait for the model to finish; tooltips like “No storeys” / “No objects” mean that data simply isn't in the file. → 12.7

Page turns on a PDF have no effect — You are reviewing a finished meeting in read-only mode, where page changes are blocked.

This is expected — read-only review keeps the page fixed. → 12.3

Note

Pan, zoom, and orbit happen inside the viewer pane only — they never move the underlying canvas, so you can explore freely without disturbing the shared layout.
